# Projet Credit Prediction

Ce projet utilise **Python** et **scikit-learn** pour prédire le risque de crédit à partir de données réelles.

## Fichiers principaux
- `app.py` : script principal de l'application
- `credit_model.pkl` : modèle entraîné
- `scaler.pkl` : normalisation des données
- `selected_features.pkl` : sélection des variables
- `test.ipynb` : notebook de test

## Installation rapide
```bash
pip install -r requirements.txt
streamlit run app.py
